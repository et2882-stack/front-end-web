# Pixel desktop site (no JavaScript)

This site uses three HTML pages and one shared CSS file. No JavaScript is used.

- `index.html`: home desktop with clickable Gallery and Works icons.
- `gallery.html`: Gallery window over the desktop background.
- `works.html`: Works window over the desktop background.
- Clicking the X in either window links back to `index.html`.
- `assets/`: your supplied background and icon assets plus the placeholder preview.

Open `index.html` in a browser, or use VS Code Live Server. Replace the repeated placeholder images and text in the HTML with your real projects.
